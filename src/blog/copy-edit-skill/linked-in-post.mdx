"Is this comment necessary?" used to show up in our code reviews a lot. AI-generated code is strong but comments need constant cleanup: restated logic, long explanations, and worn-out AI cliches.

Comment cleanup was taking precious time away from building and delivering high-quality digital services... so our engineering team wrote a skill to do the cleanup automatically!

Paul Parker writes about the Copy Edit skill: the all-too-familiar frustrations that sparked the idea, how it functions, and the results we've seen in only a few months of use.
